# README del Módulo — Guía replicable

Este README define una plantilla que puedes copiar para futuros módulos. Usa este caso (Tema principal = `APIs`) como ejemplo, pero el enfoque es genérico y directo.

## Propósito
- Estandarizar cómo organizamos un tema: bases, desarrollo principal, extensiones y práctica.
- Hacer el sistema escalable y fácil de replicar sin perder esencia.

## Estructura por niveles (convención)
- `01_Fundamentos` (opcional): Preconceptos, ideas y contexto para entender el tema sin entrar de lleno. Úsalo cuando el tema requiera base conceptual.
- `02_Tema` (obligatorio): Desarrollo principal en presente. Definiciones prácticas, cómo se hace, qué tener en cuenta. Aquí vive el núcleo del tema.
- `03_Tema_Intermedio`: Complementos y extensiones que requieren entender bien `01/02`. Reglas, ajustes, librerías que facilitan el mismo trabajo.
- `04_Tema_Avanzado`: Profundizaciones no indispensables para la meta principal. Surgen por especialización; se reserva espacio para escalar.
- `05_Planteamientos`: Pensamiento creativo y práctica. Preguntas y ejercicios para interactuar con el conocimiento y resolver casos.
- `Extras`: Útiles del proyecto (recursos, páginas, apuntes y listados que ayudan pero no forman parte del núcleo).

## Roadmap y Glosario (por tema)
- Cada tema debe tener su propio `Glosario.md` (términos) y `Roadmap.md` (lista de temas con progreso).
- Convención de progreso en roadmaps (etiquetas al inicio de cada línea):
  - `VISTO`: tema ya estudiado.
  - `INTERÉS`: próximo en prioridad.
  - `PENDIENTE`: aún no visto.
